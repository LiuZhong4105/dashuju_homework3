## 查询执行流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                         查询执行循环                                 │
└─────────────────────────────────────────────────────────────────────┘

对于每种格式 (TextFile, ORC, Parquet, RCFile):
  │
  ├─ 对于每个查询 (Query 1-5):
  │    │
  │    ├─ 1. 切换到对应数据库
  │    │     USE tpch_[format];
  │    │
  │    ├─ 2. 记录开始时间
  │    │     start_time = current_time()
  │    │
  │    ├─ 3. 执行 SQL 查询
  │    │     hive -f query[N].sql
  │    │
  │    ├─ 4. 记录结束时间
  │    │     end_time = current_time()
  │    │
  │    ├─ 5. 计算执行时间
  │    │     duration = end_time - start_time
  │    │
  │    └─ 6. 保存结果
  │          results/[format]_query[N].txt
  │          results/[format]_query[N]_time.txt
  │
  └─ 完成当前格式的所有查询
```

## 时间估算

### 单机环境 (Scale Factor 1, ~1GB 数据)

```
阶段 1: 环境准备
├─ 安装依赖        5-10 分钟
├─ 安装 Hadoop     10-15 分钟
```

## 扩展和定制

### 添加更多查询
1. 在 `queries/` 目录创建 `query6.sql`
2. 编辑 `scripts/run-queries.sh`
3. 修改 `QUERIES` 数组: `QUERIES=(1 2 3 4 5 6)`

### 测试更多格式
1. 编辑 `scripts/create-tables.sh`
2. 添加新的数据库和表定义
3. 编辑 `scripts/run-queries.sh`
4. 添加格式到 `FORMATS` 数组

### 使用不同的压缩算法
在 `create-tables.sh` 中添加:
```sql
SET hive.exec.compress.output=true;
SET mapreduce.output.fileoutputformat.compress.codec=org.apache.hadoop.io.compress.SnappyCodec;
```

### 优化性能
在 Hive 中设置:
```sql
SET hive.exec.parallel=true;
SET hive.vectorized.execution.enabled=true;
SET hive.optimize.ppd=true;
```
